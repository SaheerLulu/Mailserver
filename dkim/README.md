# DKIM keys

Generated by `scripts/gen-dkim.sh` (`make dkim DOMAIN=...`). Mounted into the
rspamd container at `/var/lib/rspamd/dkim`.

- `<domain>.<selector>.key` — **private** signing key (git-ignored, keep safe)
- `<domain>.<selector>.txt` — the public-key DNS TXT record to publish
- `selectors.map`           — maps each domain to its active selector

Back up the `.key` files together with your database — losing them means
re-keying DKIM (and republishing DNS) for every domain.
