# DNS records

Whether mail reaches inboxes (vs spam, vs rejection) is decided almost entirely
by DNS. Set these for every domain you handle mail for. Examples use
`example.com`, host `mail.example.com`, IP `203.0.113.10`.

## 1. A / AAAA — the server's address

| Type | Name               | Value          |
|------|--------------------|----------------|
| A    | `mail.example.com` | `203.0.113.10` |
| AAAA | `mail.example.com` | `2001:db8::10` (if you have IPv6) |

## 2. PTR (reverse DNS) — set at your VPS/hosting provider

`203.0.113.10  →  mail.example.com`

Configured where the IP is allocated, **not** in your DNS zone. A missing or
mismatched PTR is the most common reason self-hosted mail is blocked.

## 3. MX — where mail for the domain goes

| Type | Name          | Priority | Value              |
|------|---------------|----------|--------------------|
| MX   | `example.com` | `10`     | `mail.example.com` |

## 4. SPF — who may send for the domain

| Type | Name          | Value             |
|------|---------------|-------------------|
| TXT  | `example.com` | `v=spf1 mx -all`  |

`mx` authorises your MX host; `-all` rejects everything else (use `~all` while
testing).

## 5. DKIM — signature (generated by this server)

```bash
docker compose run --rm web python manage.py gendkim example.com
```

That prints the exact record. The selector is `mail` by default
(`--selector` to change it).

| Type | Name                          | Value                         |
|------|-------------------------------|-------------------------------|
| TXT  | `mail._domainkey.example.com` | `v=DKIM1; k=rsa; p=MIIBIj...` |

## 6. DMARC — policy + reporting

| Type | Name                 | Value                                                        |
|------|----------------------|--------------------------------------------------------------|
| TXT  | `_dmarc.example.com` | `v=DMARC1; p=quarantine; rua=mailto:postmaster@example.com; adkim=s; aspf=s` |

Start at `p=none` to monitor, then tighten to `quarantine`/`reject` once SPF and
DKIM are verified passing.

## Verifying

```bash
dig +short MX example.com
dig +short TXT example.com                  # SPF
dig +short TXT mail._domainkey.example.com   # DKIM
dig +short TXT _dmarc.example.com            # DMARC
dig +short -x 203.0.113.10                   # PTR
```

Send a test to <https://www.mail-tester.com> for an end-to-end score and
per-record diagnostics.
